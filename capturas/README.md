# Evidencias del proyecto

Esta carpeta contiene las capturas de pantalla que documentan el desarrollo práctico del Trabajo Integrador de Arquitectura y Sistemas Operativos.

## Evidencias incluidas

1. Instalación de Ubuntu.
2. Configuración de Oracle VirtualBox.
3. Código fuente del programa en Python.
4. Prueba de ejecución con números decimales.
5. Prueba de ejecución con números enteros.
6. Verificación de la versión de Python.

Las imágenes permiten demostrar el proceso de instalación, configuración, desarrollo y validación del programa realizado en el entorno virtualizado.
